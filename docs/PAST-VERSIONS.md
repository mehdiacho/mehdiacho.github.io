# Past versions

Mehdi keeps every version of anything he builds and publishes, so he and anyone else can look
back at how it developed, like a Wayback Machine. This matters most when a site moved to a new
repository instead of being updated in place: the old repository *is* the record.

## The rule

- **Never delete an old version.** Archive its repository (read-only) and keep it public.
- **Keep it viewable.** Static versions are served by GitHub Pages from their own repository,
  which shows up under this domain as `mehdiacho.tech/<repo>/`. Archived repositories keep serving.
- **Link it from the current site.** `PAST_VERSIONS` in `constants.ts` feeds the "Past versions"
  row in the footer. When the site moves to a new repository, add the old one there and here.
- Apps with tagged releases (TachiMana, Brim) already keep their history in GitHub releases.
  This list is for websites and other things published without them.
